# 《AI Agent 零基础工作方法教程》最终目录与设计规范

> 基准日期：2026-09-18
> 适用读者：完全不懂编程的大学新生、文科本硕博
> 统一认知框架：Goal → Context → Resources → Capabilities → Workflow → Verification → Reuse
> 统一任务法：8 要素（目标/材料/环境/权限/约束/过程/验收/交付）
> 核心循环：定义→规划→执行→观察→检查→（修复重执 / 交付）

## Word 样式规范

- 字体：正文宋体 11pt，标题用黑体/微软雅黑，英文用 Arial
- 配色：主色 #1F3A5F（深蓝），强调色 #B44948（暗红），辅助色 #5A8A55（绿）/ #7B6A9A（紫）
- 封面：深色背景 + 白色标题，含书名/副标题/适用读者/版本/日期
- 目录：自动生成，三级标题
- 章节首页：每 Part 新起一页，大号 Part 编号 + 标题
- 提示框/案例框/Mission 框：用表格边框实现，全书统一样式
- 页眉：左"AI Agent 零基础工作方法教程"，右当前 Part 名
- 页脚：居中页码
- 图：居中插入，图注"图 X-Y  说明"，图注用小号字居中
- 表：三线表，表头深色底白字
- 禁止：emoji、渐变背景、装饰线、廉价科技元素
