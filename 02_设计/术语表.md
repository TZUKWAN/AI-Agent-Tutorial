# Agent 术语表（全书统一译法）

> 规则：新术语第一次出现时保留英文原词，中文译法全书统一。

| 英文 | 中文译法 | 一句话解释 |
|------|----------|-----------|
| Agent | 智能体 / 代理 | 能自主规划并调用工具完成任务的AI程序 |
| Chatbot | 聊天机器人 | 只能对话、不能操作外部工具的AI |
| Copilot | 副驾驶 | 辅助人完成工作但不自主决策的AI |
| Automation | 自动化 | 按预设规则自动执行重复任务 |
| Autonomous Workflow | 自主工作流 | Agent 自主决定步骤并执行的流程 |
| Prompt | 提示词 / 提示 | 给AI的指令文本 |
| Context | 上下文 | Agent 当前能看到的所有信息 |
| Context Window | 上下文窗口 | 一次对话能容纳的最大信息量 |
| Memory | 记忆 | Agent 跨对话保留信息的能力 |
| Tool | 工具 | Agent 可以调用的外部能力 |
| Tool Calling | 工具调用 | Agent 决定调用某个工具的动作 |
| Search | 搜索 | Agent 联网查找信息 |
| Browser | 浏览器 | Agent 像人一样操作网页 |
| Computer Use | 电脑操作 | Agent 直接操控鼠标键盘操作电脑 |
| File System | 文件系统 | 计算机的文件夹和文件管理 |
| Terminal / Shell | 终端 / 命令行 | 用文字命令操作计算机的界面 |
| Code Execution | 代码执行 | Agent 运行程序代码来完成计算 |
| API | 应用程序接口 | 软件之间互相调用功能的标准化接口 |
| Connector | 连接器 | 连接外部应用（如邮箱、日历）的组件 |
| Plugin | 插件 | 给ChatGPT等平台扩展功能的模块 |
| MCP | 模型上下文协议 | Model Context Protocol，让Agent连接外部工具和数据的标准协议 |
| Skill | 技能 | 一组可复用的指令+模板+脚本，教Agent完成某类任务 |
| SKILL.md | 技能说明文件 | 描述一个Skill的名称、用途、用法的说明文件 |
| RAG | 检索增强生成 | 先从知识库检索相关资料，再让AI基于资料回答 |
| Workflow | 工作流 | 按预设步骤串联的自动化流程 |
| Sub-agent | 子智能体 | 主Agent派生出来处理子任务的独立Agent |
| Goal | 目标 | 最终要得到什么 |
| Context (工作框架) | 上下文 | Agent为完成任务需要知道的背景 |
| Resources | 资源 | 文件、网页、数据、代码等可使用的材料 |
| Capabilities | 能力 | Agent 可调用的工具和功能 |
| Verification | 验证 | 证明工作真的完成且结果可信 |
| Reuse | 沉淀/复用 | 把成熟流程保存为模板、Skill或自动化 |
| Milestone | 里程碑 | 长任务中的关键完成节点 |
| Checkpoint | 检查点 | 中途暂停让用户确认的节点 |
| Hallucination | 幻觉 | AI 编造不存在的事实 |
| Git | 版本控制工具 | 记录文件修改历史、可以回退的工具 |
| GitHub | 代码托管平台 | 存放和分享代码的网站 |
| Repository / Repo | 代码仓库 | GitHub 上的一个项目文件夹 |
| Clone | 克隆 | 把GitHub项目下载到本地 |
| Commit | 提交 | 保存一次代码修改记录 |
| Branch | 分支 | 独立修改代码的平行工作线 |
| Push | 推送 | 把本地修改上传到GitHub |
| Pull Request | 合并请求 | 请求把分支修改合并到主分支 |
| Dependency | 依赖 | 项目运行需要的其他软件包 |
| OAuth | 开放授权 | 一种让第三方应用安全登录你的账号的协议 |
| API Key | 应用程序密钥 | 调用API时证明身份的一串密码 |
| Environment Variable | 环境变量 | 存储配置信息的系统级变量 |
| Sandbox | 沙箱 | 隔离的安全运行环境 |
| RPA | 机器人流程自动化 | 传统的模拟人工操作软件的自动化技术 |
| Webhook | 网络钩子 | 事件发生时自动通知某个网址的机制 |
| Planner | 规划器 | 把大任务分解成小步骤的组件 |
| Executor | 执行器 | 实际执行步骤的组件 |
| Evaluator | 评估器 | 检查结果是否合格的组件 |
| Human-in-the-loop | 人在回路 | 关键步骤需要人确认后才继续 |
| Prompt Engineering | 提示工程 | 设计有效提示词的方法 |
| AGENTS.md | Agent规则文件 | 项目根目录下给Agent读的说明文件 |
