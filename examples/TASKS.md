# TASKS

> 任务清单（Task List）。把一件事拆成可勾选的小任务，做完一项划掉一项。
> 用途：任务中断后，凭这份清单就知道"哪些做完了、哪些还没做"，不用重头再来。
> 状态约定：`[ ]` 未开始 / `[~]` 进行中 / `[x]` 已完成 / `[!]` 卡住。
> 模板见本文件末尾。下面是一次"迷你文献调研"任务的真实记录示例。

---

## 实际记录示例（生成式 AI 与课堂 · 迷你调研）

**项目目标**：围绕"生成式 AI 对大学课堂的影响"，完成一次五阶段迷你调研，产出摘要表与调研笔记。

- [x] 1. 新建工作目录，放入 5 份 PDF 原始材料
- [x] 2. 逐份读取 5 份 PDF，提取标题 / 作者 / 年份 / 3 个关键观点
  - [!] 2b. paper03.pdf 为扫描件，无文字层 → 已在摘要表标注"读不出"，**待用户决定是否另找替代文献**
- [x] 3. 联网补搜 2026 年最新文献（目标 6-8 个来源）
  - [x] 3a. 候选 DOI 逐条点开核验 → 第 3 条打不开，已剔除
- [x] 4. 生成 `摘要表.md`（4 行可读 + 1 行标注读不出）
- [x] 5. 生成 `调研笔记.md`，含"还没搞清楚的问题"一节
- [ ] 6. **引用核验**：把笔记里每条结论的链接点开核对 ← **断点在这里，下次从这里继续**
- [ ] 7. 把核验中发现的问题修正进笔记
- [ ] 8. 最终交付：通读笔记，确认无编造引用、无死链

**当前状态（截至断点）**：第 5 步已完成，第 6 步未开始。

## 空模板（复制下面这份，每次开工新建一份）

**项目目标**：[一句话最终结果]

- [ ] 1. [第一步要产出什么]
- [ ] 2. [第二步]
  - [ ] 2a. [子步骤]
- [ ] 3. [第三步]
- [ ] 4. [第四步]
- [ ] 5. [第五步]

**当前状态**：[现在做到哪一步 / 下一步是什么 / 有没有卡住]

填写规则：

1. 每完成一项，把 `[ ]` 改成 `[x]`；卡住的改成 `[!]`，并在旁边写一句卡在哪；
2. 状态有变化就立刻更新，不要凭记忆；
3. 任务中断后，**最后一个未勾选项就是续跑起点**；
4. 不要在清单里写大段文字，一行一件事。
