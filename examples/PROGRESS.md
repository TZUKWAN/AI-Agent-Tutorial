# PROGRESS

> 进度记录（Progress）。按日期写流水账：今天做了什么、下一步是什么、遇到什么问题。
> 用途：隔了几天再回来，或对话中断后新开会话，Agent 先读这份文件就能接上，不用从头讲。
> 只往下追加，不要覆盖以前的记录。模板见本文件末尾。下面是真实记录示例。

---

## 空模板（复制下面这份，每次开工新建一份）

### YYYY-MM-DD

**今天做了什么**：
- [事项 1]
- [事项 2]

**下一步**：
- [下一步要做的第一件事]

**遇到的问题 / 待决**：
- [卡住的点 / 需要用户决定的事]

填写规则：

1. **每天一个小节**，日期顶格写；
2. 三条固定：今天做了什么 / 下一步 / 遇到的问题；
3. **只追加，不改写历史**——即使昨天的判断错了，也留着，今天另写一条更正；
4. 对话中断后，把"下一步"那一句发给新对话的 Agent，它就能接上。
