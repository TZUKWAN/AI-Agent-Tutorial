# summarize

## 何时使用
当用户要求“总结 / 概括 / 压缩 / 一句话说清”某段文本时使用本技能。

## Instructions
1. 通读输入文本，找出最核心的一个结论或动作。
2. 用不超过 40 个汉字复述，去掉举例、铺垫和修饰。
3. 如果原文含数字，数字必须原样保留，不得估算。
4. 输出格式：`摘要：<一句话>`。

## 示例
输入：“Agent 由系统提示、工具、上下文、状态、人工审批、日志六个零件拼成，其中工具调用是核心。”
输出：`摘要：Agent 由六个零件拼成，工具调用是核心。`
