# WORKLOG

> 操作日志（Work Log）。每完成一步立即追加一行，不要事后补写。
> 用途：任务中断后，凭这份日志就能还原"Agent 实际做了什么"。
> 模板见本文件末尾的空表格。下面是一次"迷你文献调研"任务的真实记录示例。

填写规则：

1. **每完成一步立即追加**，不要等到任务结束再统一补写；
2. **结果列必须写"成功 / 失败"**，失败的也要记，不能只记成功步骤；
3. **涉及文件 / 来源列必须写具体名字**，写"已读取一些文件"等于没记；
4. 最后一行的时间和内容，就是下次续跑的断点。
